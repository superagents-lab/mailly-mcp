# mailly-mcp

Open-source pieces of [Mailly](https://mailly.site)'s MCP integration.

- [`plugins/mailly`](plugins/mailly): the Mailly plugin for Claude (claude.ai,
  Cowork and Claude Code) and Codex. It connects to the hosted Mailly MCP
  server at `https://api.mailly.site/mcp` and adds a skill for working with
  email safely.

## Install in Claude Code

```
/plugin install mailly --marketplace superagents-lab/mailly-mcp
```
